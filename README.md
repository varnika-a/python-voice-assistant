# 🎙️ Voice Assistant

## Overview

Voice Assistant is a Python-based voice-controlled virtual assistant designed to perform everyday digital tasks through natural voice interaction. Powered by speech recognition and automation, the assistant listens for personalized wake words and executes commands seamlessly, creating a simple yet engaging hands-free experience.

This project represents one of my earliest explorations into software development and automation, where I combined multiple Python libraries to build a functional voice assistant capable of responding to user commands in real time.

---

## ✨ Features

* Personalized wake-word activation using **"Baby"** and **"Babygirl"**
* Real-time voice command recognition
* Instant access to Google
* Quick launch of YouTube
* Open WhatsApp through voice commands
* Play predefined songs directly on YouTube
* Interactive voice responses using text-to-speech technology
* Lightweight and responsive command execution

---

## 🛠️ Technologies Used

* Python
* SpeechRecognition
* pyttsx3
* webbrowser
* urllib.parse

---

## ⚙️ Workflow

1. Launch the assistant.

2. The system enters listening mode and waits for a wake word.

3. Say:

   * **Baby**
   * **Babygirl**

4. The assistant responds:

   > "Yes Babygirl"

5. Give commands such as:

   * Open Google
   * Open YouTube
   * Open WhatsApp
   * Play Music

The assistant processes the command and automatically performs the requested action.
